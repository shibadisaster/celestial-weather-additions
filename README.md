# Celestial Weather Additions

OFFICIAL extension/replacement for [Celestial Weather](https://mods.factorio.com/mod/celestial-weather) that reimplements the original Celestial Weather effects along with new weather effects for modded planets!

Permission from Varaxia to subsume the original mod: ![https://lite.sharx.fyi/factorio/permission.png](https://lite.sharx.fyi/factorio/permission.png)

---

This mod is intended to be highly customizable in the same way the original Celestial Weather mod is. Almost every effect/change can be modified or toggled in mod settings. Most of the weather effects included here:

## Aquilo

![https://lite.sharx.fyi/factorio/aquilo.mp4](https://lite.sharx.fyi/factorio/aquilo.mp4)

- Is significantly snowier and with a cold fog effect

## Fulgora

![https://lite.sharx.fyi/factorio/fulgora.mp4](https://lite.sharx.fyi/factorio/fulgora.mp4)

- Has fog and dust (dust is more subtle than the original, but is customizable)

## Vulcanus

![https://lite.sharx.fyi/factorio/vulcanus.mp4](https://lite.sharx.fyi/factorio/vulcanus.mp4)

- Has sulfur/acid rain, fog, and fire particles (fire is more subtle than the original, but is customizable)

## [Carna](https://mods.factorio.com/mod/carna)

![https://lite.sharx.fyi/factorio/carna.mp4](https://lite.sharx.fyi/factorio/carna.mp4)

- Has pulsating fog around plasma with turquoise particles mixed in with the snowfall

![https://lite.sharx.fyi/factorio/paracelsin.mp4](https://lite.sharx.fyi/factorio/paracelsin.mp4)

![https://lite.sharx.fyi/factorio/rabbasca.mp4](https://lite.sharx.fyi/factorio/rabbasca.mp4)

![https://lite.sharx.fyi/factorio/rubia.mp4](https://lite.sharx.fyi/factorio/rubia.mp4)

## [Vesta](https://mods.factorio.com/mod/skewer_planet_vesta)

![https://lite.sharx.fyi/factorio/vesta.mp4](https://lite.sharx.fyi/factorio/vesta.mp4)
